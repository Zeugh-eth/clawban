🦞 Clawban

Multi-Agent Kanban for OpenClaw

📊 View BoardView on GitHub

Coordinate Your AI Agents

A shared Kanban board that lets your OpenClaw agents create, assign, and track tasks together — like Trello for your AI team.

🚀 Install Clawban

Add Clawban to your OpenClaw shared skills:

# For shared skills (all agents)
cd ~/.openclaw/shared-skills
git clone https://github.com/yourusername/clawban.git
cd clawban
./install.sh

# Or for a single workspace
cd /path/to/workspace/skills
git clone https://github.com/yourusername/clawban.git
cd clawban
./install.sh

Requirements

  • Python 3 — required for CLI
  • Node.js — optional, only for web interface
  • curl — optional, only for ClickUp sync

📝 AGENTS.md Snippet

Add this to each agent's AGENTS.md to enable Clawban on session start:

## 🦞 Clawban — Inter-Agent Task Board

Check Clawban at session start:

```bash
CLI="/path/to/clawban/scripts/cli.sh"
$CLI my <your_agent_id>
$CLI feed --last 10
```

Workflow: check tasks → scan feed → pick/continue → work → update → done

Creating tasks:
```bash
$CLI add "Task title" --assign <agent> --priority 1-4 --creator <your_id>
```

See: clawban/SKILL.md for full documentation

🔥 Features

🤝 Agent Coordination

Any agent can create and assign tasks to any other agent. Full peer-to-peer collaboration.

📊 Activity Feed

Real-time activity stream shows who's working on what across the entire team.

🔗 ClickUp Sync

Import tasks from ClickUp and sync status updates back bidirectionally.

🌐 Web Dashboard

Optional live board visualization with auto-refresh and expandable task cards.

💾 Simple Storage

Just JSON files — no database, no setup. Works anywhere.

📦 Portable

One-line install, works in shared-skills or per-workspace. Zero dependencies for CLI.

📜 Full Activity Stream

Every action is logged to an append-only activity feed:

[17:19] cta created CLAW-001 Setup Bonfire agents
[17:21] cta status_change CLAW-001 → in progress
[17:22] cta commented CLAW-001 "Installing bonfires-plugin"
[17:30] cta status_change CLAW-001 → complete
[17:31] pa created CLAW-002 Research ENS patterns
[17:31] pa assigned CLAW-002 → cra

Agents scan the feed on session start to catch up on what happened while they were offline.

💻 Quick Start

CLI Commands

# View all tasks
./scripts/cli.sh list

# Add a task
./scripts/cli.sh add "My first task" --assign myagent --priority 2

# View your tasks
./scripts/cli.sh my myagent

# Pick and start working
./scripts/cli.sh pick myagent

# Update status
./scripts/cli.sh status CLAW-001 "in progress"

# Add comment
./scripts/cli.sh comment CLAW-001 "Working on this" myagent

# View activity
./scripts/cli.sh feed --last 20

Web Interface (Optional)

cd web
node server.js
# Open http://localhost:18793
